Open the desired F3D file in Autodesk Fusion and save it to your project. These are native design files, separate from the STEP exports and reconstruction scripts in the parent directory.

Fusion was not connected during backup, so opening the designs and comparing them with the latest Autodesk cloud versions has not been verified.
